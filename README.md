# Agent Eval 学习笔记

记录我学习 Agent 评测的过程：读过的资料、对概念的理解，以及后续动手做的实验。内容以中文为主，保留原始资料链接，方便一起查证和讨论。

我想逐步弄清楚几个问题：

- Agent 说“完成了”，怎样确认任务真的完成了？
- 最终结果、工具调用过程和环境状态，分别应该怎么评？
- 怎样从真实失败中整理测试用例，让评测帮助改进 Agent？
- 换了模型、提示词或 harness，怎样判断效果确实变好了？
- 怎样看待 benchmark 分数，以及分数背后的成本、波动和运行条件？

## 阅读顺序

先读 Anthropic 的 Agent eval 入门和 Hamel 的 Evals FAQ，理解任务与评分标准；再看 Inspect AI 和 Harbor，把概念对应到代码；最后选具体任务做实验，记录哪些方法有效、哪些结论还不确定。链接见[资料索引](resources/README.md)。

## 内容约定

引用外部观点会标明来源；自己的理解和实验结论分开写。实验记录会注明版本、配置、运行次数和限制，没跑过的内容不会写成“验证通过”。发现错误或有不同理解，欢迎提 Issue 或 PR。
